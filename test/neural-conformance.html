Compact neural kernel conformance

This runs the shipped WebGPU kernels against independent PyTorch fixtures. The fixture weights are untrained. Passing proves mathematical agreement within a tolerance, not good interpolation quality or real-time performance.

Serve the source directory locally: python -m http.server 8765 --bind 127.0.0.1, then open http://localhost:8765/test/neural-conformance.html in the target browser. No runtime code or video leaves the machine.
